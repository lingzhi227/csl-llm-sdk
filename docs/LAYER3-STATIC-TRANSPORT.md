# Original Layer 3: static transport and complete physical capture

The complete original Layer 3 graph now compiles with repaired packet receive
addressing and completes one position on physical WSE-3. The device runtime exits
normally, and independent readers verify the complete capture, both transport
snapshots, original parameter retention, scheduler release and durable backup.
The single-position physical and conditional operator contract is independently
accepted. The original offline numerical audit reports all operator gates passed. Its
scope is a single position with actual-operand numerical checks, not full-model
inference or bitwise agreement with the nominal CPU reference.

## Actual compiled graph

The 750x90 application contains 67,500 PEs, including the original 33,750 neural
PEs, 30,576 matrix PEs, 24 full attention heads, 136 MLP owners, 16 native sources,
24 archive sinks, 656 control relays and 611 packet endpoints. The original
weights and arithmetic are preserved; neural coordinates move to odd rows and
static packet routes occupy spacers and the control spine.

All 1,299 actual application programs were inspected. The largest ordinary
allocation plus 4,096 reserved stack bytes is 47,936 bytes, leaving 192 bytes below
the 48,128-byte ceiling. All 18,336 task entries and initial states match their
roles, and 12,626 named live banks have disjoint extents. The 14 expanded descriptor
operation models match the earlier original 003 compile exactly. This is static
storage/lifetime evidence, not a measured dynamic stack peak or a formal
whole-program memory proof.

The first full static run returned a valid READY packet but rejected its identity.
Actual code loaded one identity field 16 bytes before its intended location on
259 active receivers. Making the application callback noinline did not change
that error. A reduced negative-control compile reproduced it; moving completed
payload words to the receive allocation base corrected the addressing. A plain
shift loop produced an unresolved memmove symbol, so the accepted variant uses
an actual separate scalar helper for each word.

The full artifact verifies all 259 identity validators, all 38 scalar helper
programs covering 611 endpoints, the origin fault latch, and both nested query
credit callbacks. Each helper has one 32-bit load and store; its caller shifts
ascending indices while the receive buffer remains exclusively owned. The next
receive is armed only after application consumption. No new bank, arithmetic
rule or protocol identity predicate was introduced. The compiler pass responsible
for the original discrepancy is not established. Earlier native message-passing
failures remain preserved and are not assigned this cause.

## Complete physical capture

One original position 0 run completed one epoch, with three launches, 1,186 logical
copies and 6,217 physical copies totaling 2,335,997,556 host bytes. All PE error
states are zero; all 24 archive commits are present. Both 195-array parameter
retention passes match. The complete journal has 15,808 events and records normal
stop. Capture including stop took 110.704290510 seconds; the full guarded lifecycle
took 263.345720366 seconds. These include initialization and extensive diagnostics,
so they are not token-latency measurements.

The 600 neural capture files total 65,755,188 bytes. Four additional transport files
bring binary evidence to 604 files and 76,556,244 bytes. The full retained raw and
prefix inventory contains 1,210 files and 80,709,847 bytes. All 3,284 durable rows and
604 committed aggregates verify; no scratch rows remain.

Both complete transport snapshot pairs independently satisfy the reconstructed
traffic contract:1,223 flows and 2,532 directed edges with packets over the combined
1,266-edge relay/endpoint tree. All 2,700,000 snapshot words, counts and released
source/edge leases pass. The hardware job reaches SUCCEEDED; the system has no
assignment and all owned processes are absent. These are scheduler/process
release facts, not a verified billing-ledger statement.

## Numerical evidence and limits

The original audit runs only after device release and imports no SDK. It checks
3,913,728 local conditional matrix rows and 30,576 predetermined exact FP32 FMA
samples comprising 2,935,296 multiplication slots. It verifies actual reduction
chains, BF16 conversions, tensor handoffs, normalization, all 24 QK/RoPE and
attention paths, cache replicas and tails, MLP nonlinear operations and both
residual additions. All implemented operator gates report passed. Its 17.199654452
seconds are offline validation time.

The final BF16 vector differs from the nominal CPU reference at 346 of 5,120
values. Maximum absolute error is 0.00390625, maximum relative error over nonzero
reference values is 0.3333333333333333, and maximum error where the reference is
zero is 0.0001220703125. The audit records these differences; they are not an
end-to-end acceptance tolerance. Local checks condition on observed operands,
and the audit explicitly reports no source-propagated whole-layer enclosure.
Standalone archived trigonometric probes are not an additional numeric gate;
QK/RoPE conversion and actual-operand gates retain their stated scope.

An independent reader additionally checks a different exact FMA sample at every
matrix PE, all reduction and active-handoff words, KV prefixes and tails, and
residual reconstruction. It uses the same qualified integer FP32 helper, so it
is independent input selection and reconstruction, not a second arithmetic engine.

Only position 0 of Layer 3 has run through this complete path. Nonzero-position
cache evolution, repeated decode/reset, recurrent layers, all 64 layers, logits,
text generation and checkpoint restoration across the three 20/24/20 stages remain
open. The current 90-row single-layer verification layout cannot simply be
repeated 20 times within the 1,172-row fabric; stage placement needs its own budget
and actual compiled-fit checks.

The first static hardware failure, both ineffective compiler workarounds and all
previous native transport failures remain part of the evidence history. The
new host early-origin-error stop branch was not exercised by this successful run.
