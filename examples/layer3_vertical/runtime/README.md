# Original vertical Layer3 runtime source

Every source-map entry is byte-identical to the frozen qualification candidate.
The [report](../../../docs/LAYER3-VERTICAL.md) records the accepted finite scope,
nominal BF16 differences and preserved inspection failures. These are historical
deployment and validation sources, not a portable one-command launcher. Source
generation retains dependencies on previously qualified development candidates;
the complete generated CSL and placement maps are included here.

No original weights, raw captures, ELF/SDK binaries, private input roots or live
admissions are included. Original inspection/source gates remain unchanged,
including the disclosed migrated SRAM-check bug. A new deployment needs qualified
inputs, actual bank bindings, the correct layer-specific SRAM policy, independent
resource checks and a new frozen manifest/admission. Do not remove gates to make
these archived sources run. Host numerical auditing runs only after device release.
