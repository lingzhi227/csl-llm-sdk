## Ownership and remaining work

The frontend launches each packet automatically and releases its source only
after the packet DMA callback. Gated outputs remain leased until successor
consumption; an output-ready notification cannot retire them. Initial/reset
outstanding debts are zero, and admission creates the actual192-frame and
worker-marker obligations. Old host commands for packet launch/release are
removed. Diagnostic captures and forced delayed callbacks are absent here.

Each recurrent worker retains the qualified P47 paired return and header data
task. Its decoder and value scratch are shared with the resident projection only
across drained phases. A remote return marker alone does not prove that every
source-side callback has executed. The integrated controller must respect each
local cohost's admission fence; SDK qualification snapshots are not a serving
protocol. Routes are static, and this candidate does not replace the model with
a temporal weight overlay.
